# 会場コンテンツテンプレート

電子基板には載せない。紙・看板・スタッフ運用で使う。

## 4スポット共通フォーマット

| フィールド | 記入例 |
|------------|--------|
| スポットID | A |
| 設置場所 | 公演・滑り台の下 |
| 手がかり（現物） | 問題用紙 `[と][ざ][?][ぼ]` |
| 解き方メモ（スタッフ用） | 東西南北の頭文字 → `?`=南 |
| 導かれる1文字 | ナ |
| 入力順の番号 | 1文字目 |

## スタッフ台本（最小）

1. 基板を渡す。「4か所を回って、1文字ずつメモしてね」
2. 4文字そろったら基板で入力し、`判定` を押す
3. `CLEAR!` を見せたらクリア
4. `OVER` のときは電源OFF→ONで再挑戦
